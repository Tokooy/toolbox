# 美债收益率看板 · US Treasury Yield Dashboard

一个本地运行的网页应用：用三种颜色展示美国 **2 年期 / 10 年期 / 30 年期**国债收益率
**2020 年至今**的走势曲线，支持滚轮缩放时间轴、按需联网增量更新数据。

本目录是该工具的**完整实现**（前后端分离，可独立运行，也可被工具台 `hub` 托管）。

> English version: [README_en.md](README_en.md)

## 一、目录结构

```
apps/treasury/
├── app.json              应用清单（工具台据此生成侧栏按钮与接口路由）
├── backend/              后端，自下而上四层，互不越层
│   ├── fred.py             网络层：从 FRED 下载 DGS2 / DGS10 / DGS30
│   ├── store.py            存储层：本地缓存（CSV / meta.json）读写与原子替换
│   ├── service.py          业务层：增量更新 refresh_data() / 组装数据 load_data()
│   └── api.py              接口层：/api/treasury/*
├── frontend/             前端
│   ├── panel.js            走势图面板（Vue + ECharts，工具台与独立站点共用）
│   └── panel.css           面板样式
├── standalone.py         独立运行入口（只跑这一个工具的网页）
├── seed_data.py          可选：用 data/treasury/raw 里的原始 CSV 重建缓存（不联网）
├── environment.yml       可选：conda 环境定义（后端零第三方依赖，装它只是为了隔离运行时）
└── requirements.txt      说明：本工具零第三方依赖
```

## 二、功能特性

- **三条收益率曲线**：2 年期（琥珀色）、10 年期（天蓝色）、30 年期（紫罗兰色），
  支持图例开关、十字光标悬浮查看每日数值；
- **横轴完整日期**：默认按年分格，滚轮放大后自动细化为季度 / 月份 / 日期，悬停显示具体日期；
- **最新行情卡片**：三个期限的最新收益率、较前一交易日涨跌、近 90 个交易日迷你走势图，
  以及 **10Y − 2Y 期限利差**（倒挂时高亮警示）；
- **滚轮缩放 / 拖拽平移**：基于 ECharts inside dataZoom，右上角按钮一键还原视图；
- **按需更新**：只有点「获取最新数据」才联网，平时完全离线读本地缓存；
- **增量更新**：只取各序列最后一条数据之后的缺失天数，失败时旧缓存原样保留；
- **自动代理**：启动时探测环境变量与常见本地代理端口（7890 / 7897 / 1080 等，兼容 Clash / v2ray）。

## 三、三种使用方式

```bash
# 1) 工具台里打开（推荐日常使用）
python hub/server.py                       # http://127.0.0.1:8080 → 左侧「美债收益率」

# 2) 只启动这一个工具的网页
python apps/treasury/standalone.py         # http://127.0.0.1:5000
PORT=9000 python apps/treasury/standalone.py

# 3) 用原始 CSV 重建本地缓存（不联网，一般不需要）
python apps/treasury/seed_data.py
```

后端是**纯 Python 标准库**实现，任何 Python 3.9+ 都能直接跑，不必装任何包。

## 四、数据来源与权威性

| 项目 | 说明 |
| --- | --- |
| 数据源 | [FRED — 圣路易斯联邦储备银行](https://fred.stlouisfed.org/)（美联储官方数据发布渠道） |
| 序列 ID | `DGS2` / `DGS10` / `DGS30`（2 / 10 / 30 年期恒定到期收益率，日频收盘值，单位 %） |
| 频率 | 日频，仅交易日有数据（节假日无数据，图中自动断线） |
| 时间范围 | 2020-01-01 至今（仓库内置快照的截至日期见 `data/treasury/meta.json`） |
| 原始存档 | `data/treasury/raw/DGS*.csv` —— FRED 原始下载文件，可逐行比对溯源 |

数据目录（默认 `<仓库根>/data/`，可用环境变量 `TOOLBOX_DATA_ROOT` 覆盖）：

```
data/treasury/
├── raw/DGS{2,10,30}.csv    FRED 原始 CSV 存档（随仓库提交）
├── treasury_yields.csv     合并后的本地缓存（date, DGS2, DGS10, DGS30）
└── meta.json               元信息（数据截至日期、行数、更新时间、本次更新模式）
```

写盘采用「临时文件 + `os.replace`」原子替换：写盘中途异常，旧缓存保持完好。

## 五、接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/treasury/data` | 读取本地缓存并组装图表数据（从不联网，秒回；无缓存返回 `no_data`） |
| POST | `/api/treasury/refresh` | 按需联网增量更新，返回更新后的完整数据与本次更新元信息 |

工具台与独立站点的接口路径**完全一致**，因此同一份前端面板两边通用。

## 七、抓取策略（大陆网络环境实测有效，勿轻易改动）

1. **自动探测代理**：先看 `HTTPS_PROXY` 等环境变量，再探测常见本地代理端口（7890 / 7897 / 1080 …）；
2. **不携带浏览器 UA**：FRED 边缘节点（Akamai）会黑洞「浏览器 UA + 非浏览器 TLS 指纹」的组合请求
   （表现为连上却一直不返回），诚实的默认 UA（curl / urllib）可以稳定放行；
3. **系统 curl 优先、urllib 兜底**：curl 强制 HTTP/1.1 规避部分网络对 HTTP/2 帧的干扰，自带有限次重试；
4. **增量起点取「本地最后日期当天」**：FRED 的 `cosd` 参数超出其数据范围时会回退返回全量历史，
   因此取当天而非次日更稳；重复日期直接覆盖，还能顺带修正最近一个交易日的数值修订。

## 八、常见问题

**Q1：点「获取最新数据」提示失败？**
A：确认本机可访问 FRED；若开了代理但没设环境变量，服务启动时一般能自动探测到；
也可以显式指定后重启：`export HTTPS_PROXY=http://127.0.0.1:7890`。失败不影响已缓存数据的展示。

**Q2：为什么「今天」没有新数据？**
A：FRED 数据日期是**美国交易日（美东时间）收盘值**，与北京时间有约 12–13 小时时差，
   “今天”有没有新数据以 FRED 实际发布为准；没有新数据时页面会提示「已是最新」。

**Q3：图表空白？**
A：ECharts 由工具台本地托管（`/static/vendor/echarts.min.js`，无 CDN）。硬刷新一次（Ctrl+F5）即可。

**Q4：想删掉数据重新获取？**
A：删除 `data/treasury/treasury_yields.csv` 后重启即可；页面会提示「无本地数据」，
   点「获取最新数据」会全量重新获取（不联网时页面也能立刻打开，不会卡住）。

**Q5：为什么 2020-01-01 没有数据？**
A：那天是元旦假期，FRED 只发布交易日数据，2020 年首条是 2020-01-02。

**Q6：数据会不会失真？**
A：内置快照是发布时刻的真实数据；`data/treasury/raw/` 保留了 FRED 原始 CSV，可与任何来源核对。

## 九、技术栈

- **后端**：Python 标准库（`http.server` / `urllib` / `csv` / `subprocess`），零第三方依赖，
  线程安全 + 原子写回；HTTP 框架来自 `core/http.py`；
- **前端**：Vue 3 + ECharts 5（均由工具台本地托管，无 CDN、无构建步骤）；
- **数据**：FRED 官方 CSV 下载接口，无需 API Key。
