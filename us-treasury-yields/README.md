# 美国国债收益率看板 · US Treasury Yield Dashboard

一个本地运行的网页应用：**从 2020 年至今**，用三种颜色分别展示美国 **2 年期 / 10 年期 / 30 年期** 国债收益率的走势曲线，并支持鼠标滚轮缩放时间轴、按需联网更新数据。

> English version: [README_en.md](README_en.md)

## 一、功能特性

- **三条收益率曲线**：2 年期（琥珀色）、10 年期（天蓝色）、30 年期（紫罗兰色），同屏对比，支持图例开关、十字光标悬浮查看每日数值。
- **横轴日期**：完整 `YYYY-MM-DD` 格式；默认视图每年一个刻度（按年分格、不拥挤），滚轮放大后自动细化为季度 / 月份 / 日期；悬停时工具框顶部显示具体日期。
- **最新行情卡片**：三个期限的最新收益率、较前一交易日涨跌、近 90 个交易日迷你走势图，以及 **10Y − 2Y 期限利差**（倒挂时高亮警示）。
- **滚轮缩放时间轴**：鼠标在曲线区域滚动滚轮即可放大 / 缩小时间跨度，按住拖拽平移，右上角按钮一键还原（基于 ECharts inside dataZoom）。
- **按需更新数据**：右上角「获取最新数据」按钮 —— 点击后才联网从 FRED 获取数据；平时运行完全不联网，直接读取本地缓存。
- **增量更新**：已有本地数据时，只从最后一条数据的日期开始获取缺失的那几天，**不重复下载全量历史**，通常几秒完成；若 FRED 尚未发布新交易日数据会提示「已是最新」。
- **真实权威数据**：全部数据来自美国圣路易斯联邦储备银行（Federal Reserve Bank of St. Louis）的 FRED 数据库，序列为 DGS2 / DGS10 / DGS30（美国国债恒定到期收益率，日频收盘值），原始下载文件保存在 `data/raw/` 中可溯源核对。

## 二、数据来源与权威性

| 项目 | 说明 |
| --- | --- |
| 数据源 | [FRED — 圣路易斯联邦储备银行](https://fred.stlouisfed.org/)（美联储官方数据发布渠道，全球宏观经济数据的权威标准） |
| 序列 ID | `DGS2` / `DGS10` / `DGS30`（Market Yield on U.S. Treasury Securities at 2/10/30-Year Constant Maturity） |
| 频率 | 日频，交易日收盘值（节假日无数据，图中自动断线） |
| 时间范围 | 2020-01-01 至今（本仓库内置快照截至 2026-08-12，1725 个交易日） |
| 原始存档 | `data/raw/DGS2.csv`、`data/raw/DGS10.csv`、`data/raw/DGS30.csv`（本次下载的 FRED 原始 CSV，可逐行比对） |

> FRED 的「恒定到期收益率」由美国财政部与美联储根据二级市场国债实际成交价计算，是全球利率定价与货币政策分析的标准参考数据。

## 四、如何运行（重点）

### 4.1 安装 conda

若尚未安装，请先安装 [Miniconda](https://docs.conda.io/en/latest/miniconda.html) 或 Anaconda（本机已装 Anaconda 可跳过）。

### 4.2 用 conda 创建虚拟环境

在**项目根目录**（`us-treasury-yields/`）下打开终端，执行：

```bash
# ① 按 environment.yml 创建名为 treasury 的虚拟环境（python 3.11）
conda env create -f environment.yml

# ② 激活环境
conda activate treasury
```

> 本项目后端为**纯 Python 标准库实现，零第三方依赖**（不需要 pip install 任何包），
> conda 环境用于隔离 Python 运行时，从根源上避免依赖包冲突。

### 4.3 启动服务

```bash
python server.py
```

看到如下输出即启动成功（会自动打开浏览器）：

```
美国国债收益率看板已启动：http://127.0.0.1:8080
按 Ctrl+C 停止服务
（若无本地缓存，服务会在后台自动尝试从 FRED 获取一次，失败不影响使用）
```

### 4.4 打开网页

浏览器访问 **http://127.0.0.1:8080** 即可看到 2020 年至今的三条收益率曲线。

> 本仓库已内置数据快照，开箱即用、无需网络。
> 若本地缓存不存在：服务启动时会在后台自动尝试从 FRED 获取一次（不阻塞启动）；
> 页面会提示「暂无本地数据」，点击「获取最新数据」即可按需联网获取。

### 4.5 停止服务

在终端按 `Ctrl+C`。

## 五、按钮「获取最新数据」怎么用

- 位置：页面右上角（翡翠绿渐变按钮）。
- 行为：**点击后**才联网从 FRED 获取数据，其余时间完全不联网。
- **增量更新**：已有本地数据时，只请求最后一条数据日期之后缺失的那几天（三个序列各自计算起点，不会漏取），**不重复下载 2020 年以来的全量**；首次（无缓存）时才全量获取。
- 完成后弹窗显示结果：新增 N 天 / 已是最新（FRED 尚未发布更新的交易日数据），页面自动刷新曲线与「数据截至」时间。
- 若网络失败，弹窗展示错误详情并停留，本地已缓存的数据不受影响。
- **时区说明**：FRED 数据日期为**美国交易日（美东时间）收盘值**，与北京时间存在约 12–13 小时时差，所以"今天"是否有新数据以 FRED 实际发布为准。

## 七、常见问题（FAQ）

**Q1：浏览器里图表空白？**
A：图表库 ECharts 通过 CDN 加载，请确认浏览器能访问 `cdn.jsdelivr.net`（刷新一次即可重试）。

**Q2：点按钮提示「从 FRED 获取数据失败」？**
A：服务端已做多种网络兼容，请按顺序排查：
1. **自动代理**：服务启动时自动探测环境变量代理及常见本地代理端口（7890 / 7897 / 1080 等，兼容 Clash / v2ray），探测到即自动走代理获取；
2. **无浏览器 UA**：FRED 边缘节点（Akamai）会黑洞「浏览器 UA + 非浏览器指纹」的组合请求，本项目使用诚实默认 UA（实测稳定放行）；
3. **HTTP/1.1 + 重试**：强制 HTTP/1.1 规避部分网络对 HTTP/2 帧的干扰，并自动重试；
4. 若仍失败，请确认本机网络可访问 FRED（或配置 `HTTPS_PROXY` 环境变量后重启）；失败不影响已缓存数据的展示。

**Q3：8080 端口被占用？**
A：启动时会直接给出换端口提示。先确认没有旧实例在运行（`ss -tlnp | grep 8080`），或换端口：`PORT=9000 python server.py`，然后访问 http://127.0.0.1:9000。

**Q4：想删掉数据重新获取？**
A：删除 `data/treasury_yields.csv` 后重启即可；页面会提示「暂无本地数据」，点击「获取最新数据」会全量重新获取。删除后页面仍能立即打开（不会卡死等待网络）。

**Q5：为什么 2020-01-01 没有数据？**
A：该日是元旦假期，FRED 仅发布交易日数据，2020 年首条数据为 2020-01-02。

**Q6：数据会不会过期/失真？**
A：内置快照是发布时刻的真实数据；点击按钮即可拉取到最新。原始文件保留在 `data/raw/`，可与任何来源核对。

## 八、技术栈

- **后端**：Python 3.11（标准库 `http.server` / `csv`；零第三方依赖，线程安全 + 原子写入）
- **前端**：原生 HTML/CSS/JS + ECharts 5（CDN 加载）
- **数据**：FRED（圣路易斯联储）官方 CSV 下载接口，无需 API Key
- **抓取策略**：系统 curl 优先（强制 HTTP/1.1、浏览器级请求头、自动重试），urllib 兜底；**不携带浏览器 UA**（Akamai 会黑洞伪装请求）；**自动探测代理**（环境变量 + 常见本地代理端口）；**增量更新**（只取缺失天数，原子写回，失败保留旧数据）
